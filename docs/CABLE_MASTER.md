# ケーブルマスター仕様

対応種類: CV / VVF / VVR / CVT / IV。

| 種類 | サイズ単位 | 構成 |
|---|---|---|
| CV | mm² (sq) | 1C〜4C（実在製品のみ） |
| VVF | 導体径 mm | 2C〜4C（実在製品のみ） |
| VVR | mm² (sq) | 2C〜4C（実在製品のみ） |
| CVT | 各導体mm² | トリプレックス |
| IV | mm² (sq) | 単心 |

主キーは製品・仕様を識別する不変ID。表示名をキーにしない。属性: 導体材質、絶縁、定格温度、外径/形状、質量、抵抗、リアクタンス、基準許容電流、適用条件、メーカー、出典、版、確認日、検証状態。

製品が存在しない組み合わせは選択肢に出さない。未登録数値はnullとし、推測で埋めない。メーカー間の寸法差を扱えるデータモデルにする。

初期サンプル `src/data/cables/sample.unverified.json` は構造検証用であり、計算用マスターではない。
