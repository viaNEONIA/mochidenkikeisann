# Phase 0 規程・メーカー資料の検証台帳

状態: **検証前・提案**。本台帳はデータ収集・承認のための管理方法を定める。規程の最新版や適合数値を確認済みと主張するものではない。

## 目的
許容電流、電圧降下、電線管収容、ケーブルラック幅、保護機器選定に使用する根拠の出典・適用条件・使用許諾・改訂状況を追跡する。

## ステータス
- **unverified**: 原典未確認。計算・自動選定に使わない
- **source-checked**: 原典と版・発行元を確認したが、適用条件または利用許諾の確認が未完了
- **validated**: 原典、版、適用条件、転記精度、使用条件を検証済み
- **superseded**: 後継版を確認したため新規計算では利用しない
- **blocked**: 利用許諾・内容・適用範囲の問題により利用禁止

## 検証フロー
1. 原典の正式名称、発行元、版、発行年月、資料URLまたは所蔵位置を記録。
2. 使用する条項・表・図・式を特定し、適用範囲と例外を記録。
3. 使用許諾・著作権・再配布可否を確認。許諾のない表の全文をGitHubに掲載しない。
4. 対象ケーブル・管・ラック・機器の型式、寸法単位、布設条件を照合。
5. 別担当または独立した手計算・資料照合で転記を検証。
6. 検証者、日付、版、検証証跡を記録し、レビュー承認後に validated とする。
7. 改訂時は旧レコードを保持し、新版を別IDとして追加。保存済み計算結果の参照版を変更しない。

## 優先する出典カテゴリ（最新版未確認）
| 分類 | 確認対象 | 必要なデータ |
|---|---|---|
| 法令 | 電気設備に関する技術基準および解釈 | 適用範囲、保護、施工条件 |
| 内線規程 | JEAC 8001 | 布設・保護・電線管等の適用表 |
| 規格 | 関係するJIS | 製品寸法、性能、試験条件 |
| 電線メーカー | CV、VVF、VVR、CVT、IVの製品資料 | 公称寸法、導体径/断面積、心数、外径、許容電流条件 |
| 電線管メーカー | 管種別の製品資料 | 呼び径、実内径、適用寸法 |
| ラックメーカー | ケーブルラックの製品資料 | 幅、許容荷重、支持間隔 |
| 遮断器メーカー | 遮断器・モーター保護器資料 | 定格、遮断容量、適用条件、協調 |

## 受入条件
- 各機能で参照するデータに validated のレコードが存在する。
- 数値の単位と適用条件が一致する。
- 出典の版を計算結果とともに保存できる。
- 未確認の数表や適用外条件で「適合」を返さない。
- 不明・矛盾・版の更新を検出したら対象機能を要確認/未判定に戻す。
