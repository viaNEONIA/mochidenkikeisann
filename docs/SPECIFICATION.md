# 機能仕様 v1.2

## 画面
S01 ホーム / S02 動力・一般負荷 / S03 電圧降下 / S04 電流→電線 / S05 電線→許容電流 / S06 電線管 / S07 ラック / S08 一時保存・連続計算 / S09 結果詳細 / S10 PDF・CSV / S11 設定。

## S01
ホームに動力選定と30A以下の電圧降下入力を常設。他機能は切替ボタン。詳細条件は専用画面で入力。

## S02
負荷種別、電源、電圧、定格値(kW/A/kVA)、力率、モーター効率、始動方式、ケーブル、距離、布設方式、温度、集合条件を入力。電流・入力電力・ケーブル候補・遮断器候補・電圧降下・判定を表示。軸出力と入力電力を混同しない。遮断器の確定は保護協調・始動特性・遮断容量・メーカー条件を要する。

## S03
ホームは0超〜30A、詳細画面は30A超も対応。相数、電圧、距離、ケーブル、温度、力率、抵抗、リアクタンスを扱い、降下V、%、末端電圧を表示。単相3線の不平衡は専用モデル。許容降下率は回路条件別設定。

## S04/S05
電流から条件を満たす電線候補を抽出。電線から基準許容電流・補正係数・補正後許容電流を表示。採用・不採用理由と参照根拠を記録。

## S06
管種・呼び・ケーブル種類/サイズ/本数を入力。占積率、収容可否、必要管サイズを表示。規程上の収容表や専用手法があれば単純占積率より優先。

## S07
複数行のケーブル種類・サイズ・本数から、外径・配列・間隔・余裕・荷重・支持条件を考慮して標準ラック幅候補を表示。幅だけで適合確定しない。

## S08〜S10
計算ID、名称、条件、結果、根拠、参照資料版、計算エンジン版、日時、判定をIndexedDBへ保存。次の計算へ共通条件を引き継ぐ。PDF簡易/詳細、CSV、JSONバックアップ・復元を提供。保存済みの再計算は新規レコードとする。

## 判定
適合 / 不適合 / 要確認 / 未判定。数値計算の成否と規程適合判定は独立して管理。

## 対象外（将来実装）
計算結果の改訂履歴管理、変更前後の差分比較。
