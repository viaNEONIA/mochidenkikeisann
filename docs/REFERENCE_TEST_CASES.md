# Phase 0 計算基準試験ケース設計

状態: レビュー待ち。規程の適合性を保証するものではない。

## 試験原則
- **数式単体テスト**と**法令・規程適合判定テスト**を分離する。
- 以下の数値例は単位換算・演算を検証するための**人工データ**。実ケーブルの抵抗値、許容電流、遮断器定格として使用しない。
- 検証済みの出典・版・条件が揃うまで、ケーブル・遮断器・管径・ラック幅の適合結果は「未判定」。
- 入力条件と計算根拠は同一結果オブジェクトから保存・表示・出力する。

## D. 合格の考え方
- 数式単体: 期待値に対し絶対誤差1e-5以内（表示丸め前の値を比較）。この閾値は試験用の暫定案。
- 規程適合: 出典付きの基準ケースを別途用意し、適用条件と照合。現時点では**合格判定不可**。
- 表示: 単位、入力、警告、根拠IDの欠落がないこと。
- 単相3線、リアクタンス、温度補正、布設補正、モーター保護の正解ケースは仕様確定後に追加。
