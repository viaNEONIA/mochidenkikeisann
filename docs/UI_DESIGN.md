# UI設計

- スマートフォン縦画面優先、片手操作。主要ボタンは画面下半分、操作対象44×44 CSS px以上を目安。
- ホームに動力選定・電圧降下の入力カードを常設。下部ナビ: ホーム/計算一覧/一時保存/設定。
- ケーブル選択は種類→サイズ→芯数の連動ドロップダウン。VVFは導体径mm、他は断面積mm²。CVTはトリプレックス、IVは単心として表示。
- 入力時は数字キーボードを優先。可視領域変化時に入力欄へスクロールし、固定ボタンをキーボードに重ねない。
- 詳細条件は折りたたみ、計算結果は同画面で表示。入力変更時に旧結果を無効化。
- 結果には「計算根拠」「一時保存」「次の計算」を配置。根拠は式、代入値、中間値、係数、参照資料、判定状態を表示。
- オフライン・保存失敗・規程データ未検証を明確に表示。色だけに依存しない。
- 実機でAndroid Chrome/iOS Safariのキーボードとホーム画面追加を検証。
