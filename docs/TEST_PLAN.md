# Phase 0試験計画

| ID | 試験 | 合格条件 |
|---|---|---|
| P0-01 | Androidホーム画面追加 | 起動できる |
| P0-02 | iPhoneホーム画面追加 | 起動できる |
| P0-03 | オフライン起動 | 通信なしで画面が表示される |
| P0-04 | ソフトキーボード | 入力欄・単位が隠れず操作可能 |
| P0-05 | ケーブル選択 | 種類→サイズ→構成が連動 |
| P0-06 | 電圧降下数値 | 独立計算した期待値と許容差内一致 |
| P0-07 | 計算根拠 | 式・代入値・結果が一致 |
| P0-08 | IndexedDB | 再起動後に保存結果が復元 |
| P0-09 | 連続計算 | 共通条件のみ正しく継承 |
| P0-10 | JSONバックアップ | 復元後データ一致 |
| P0-11 | 未検証規程 | 「適合」判定しない |
| P0-12 | PDF/CSV | 条件・結果・根拠の一致 |

追加: 入力境界、負値、ゼロ除算、単位変換、三相/単相の分岐、単相3線不平衡、丸め、規程データ欠落、ストレージ障害。期待値と出典をテストケースに紐付ける。

Phase 0合格前に本格的な選定機能実装を開始しない。
