# 規程・出典管理

基準方針: 開発時点で確認できる最新版を採用する。ただし案件ごとの適用版、法令・内線規程・JIS・メーカー資料を区別する。版を確認できない場合は「未検証」。

出典レコード: sourceId、資料名、発行元、版/改正日、条項・表番号、URLまたは参照方法、確認日、利用権限、検証者、検証状態、対応データID。

状態: verified / provisional / missing / outdated。verified以外の値から規程適合を確定しない。

内線規程の表・文章は権利確認なくリポジトリへ転載しない。原典を合法的に入手し、数値を照合する。公式な最新版の確認はPhase 0の作業。
