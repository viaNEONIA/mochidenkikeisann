# ChatGPT Work / Codex 引き継ぎ指示

## 目的
GitHubを唯一の仕様正本として、電気工事計算支援PWAのPhase 0技術検証を進める。

## 最初に実施すること
1. READMEとdocs配下をすべて確認。
2. 矛盾、不足、実装リスクをIssue候補に整理。
3. Phase 0の作業計画と試験ケースを具体化。
4. featureブランチとPRで変更を管理。
5. 計算エンジンの検証可能な最小プロトタイプから開始。

## 制約
- 確定仕様を無断変更しない。
- 内線規程等の数表を推測・無断転載しない。
- 未検証値で「適合」判定しない。
- 計算結果の改訂履歴・差分比較は実装しない。
- Phase 0合格前に本格機能実装へ進まない。
- 試験結果と再現手順をPRに記載する。

## 初回依頼文
「このリポジトリのREADMEとdocsをすべて読み、確定仕様と未確定事項を整理してください。仕様を無断変更せず、Phase 0の検証計画・テストケース・リスク一覧を作成し、ブランチとPRで管理してください。Phase 0の合格までは本格実装を開始しないでください。」
