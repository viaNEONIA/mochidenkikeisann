# 要求仕様 v1.2

## 確定
- PWAとしてスマートフォンで利用する。
- 片手操作を優先し、頻用する2機能をホームに直接表示する。
- 個別機能はホームの切替ボタンから専用画面へ遷移する。
- ケーブル種類とサイズは段階的ドロップダウンで指定する（例: CV → 2sq → 3C）。
- ソフトウェアキーボードで入力・計算・結果表示が隠れないUI。
- 電源は単相・三相の両方に対応する。
- 動力は一般用途を対象とする。
- 対応ケーブルはCV、VVF、VVR、CVT、IV。
- 適用規程は最新の版を確認する方針。
- 計算根拠の本格的な実装は将来フェーズとし、現段階では根拠を管理する設計を優先する。

## 対象機能
動力選定、30A以下の電圧降下、電流→ケーブル、ケーブル→許容電流、電線管収容、ラック幅、連続計算・一括出力。

## 品質
入力検証、条件不足表示、単位明記、根拠の追跡性、スマートフォン実機試験。
