# 電気工事計算支援PWA

電気設備工事の施工管理・現場確認向け、オフライン対応PWA（設計段階）。

> **現状:** 仕様 v1.2 / 実装未着手。電線・遮断器等の選定結果を実務に使用できる段階ではありません。

## 確定した対象
- 電源: 単相100/200V、三相200/400V（単相3線の不平衡は専用処理）
- 負荷: モーター、ポンプ、ファン、一般動力
- ケーブル: CV、VVF、VVR、CVT、IV
- ホーム常設: 動力・一般負荷選定、30A以下の電圧降下簡易計算
- 個別画面: 電流→電線、電線→許容電流、電線管収容、ケーブルラック幅
- 連続計算・一時保存・計算根拠・PDF/CSV・JSONバックアップ
- 片手操作・ドロップダウン・ソフトキーボード対策・オフライン

## 開発前の重要事項
規程やメーカー資料の数表・補正係数は未収録。適用法令、内線規程、メーカー仕様は版と出典を確認して登録する。未検証データで「適合」と判定しない。遮断器の最終選定には保護協調・始動特性等の確認が必要。
